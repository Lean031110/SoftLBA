## Archivos creados

### 1. `src/lib/currency.ts`
Utilidades de conversión monetaria CUP/USD.

- Tipo `Currency = 'CUP' | 'USD'` y `PaymentLike = { amount: number; currency: string; method?: string }`.
- `convertToCup(amount, currency, usdToCupRate)`: USD → CUP multiplicando por tasa. CUP se mantiene. Fallback defensivo a 320 si la tasa es inválida.
- `convertFromCup(amount, targetCurrency, usdToCupRate)`: CUP → USD dividiendo por tasa. CUP se mantiene.
- `convertCurrency(amount, from, to, usdToCupRate)`: Conversión arbitraria vía CUP como pivote.
- `getTotalInCurrency(payments, targetCurrency, usdToCupRate)`: Suma pagos convirtiendo a la moneda destino.
- `breakdownPayments(payments, usdToCupRate)`: Devuelve `PaymentBreakdown` con `totalCashCUP`, `totalCashUSD`, `totalTransferCUP`, `totalTransferUSD`, `totalOther`, `totalCUP`, `totalUSD`, `byMethod`.
- Helpers: `isCashMethod`, `isTransferMethod`, `currencyForMethod` (devuelve USD para métodos que terminan en `_USD`, ZELLE, BANCARIA_USD; CUP para el resto), `formatCurrency`.

## Decisiones técnicas

1. **Currency.ts agnóstico al tipo de Payment**: Usa `PaymentLike = { amount: number; currency: string; method?: string }`. Permite reusarlo con resultados de Prisma o con datos de testing.

2. **breakdownPayments clasifica COMBINADO en totalOther**: Los métodos no estándar (COMBINADO u otros) no se suman a cash/transfer (totalOther), PERO se suman al `totalCUP` en su moneda original para no perderlos en el total agregado. Si el método trae `currency: 'USD'` se cuenta como transfer USD (aproximación).

3. **DailyClose mantiene escalares en CUP equivalente**: `totalCash`, `totalTransfer`, `totalSales` siguen siendo escalares (en CUP equivalente) para no romper la UI existente. Los totales por moneda original quedan registrados en el audit log.

4. **FinanceEntry preserva moneda original**: Cada FinanceEntry creado al cerrar mantiene `currency: 'USD'` o `currency: 'CUP'` según el método. FIX 6 no altera esto.

5. **Realtime-service no depende del módulo auth de Next.js**: Es un mini-servicio Bun separado. Se duplicó la lógica de verificación HMAC usando Web Crypto API (compatible con Bun). Si el algoritmo cambia en `src/lib/auth/token.ts`, hay que actualizar también `mini-services/realtime-service/index.ts`.

6. **CORS permite peticiones sin Origin**: Para no romper tests y administración local (curl, mismo host). En producción, `ALLOWED_ORIGINS` puede restringir más.

7. **Código de verificación de token idéntico en 3 lugares**: `middleware.ts`, `src/lib/auth/token.ts` y `mini-services/realtime-service/index.ts`. Si cambia el algoritmo en uno, hay que cambiarlo en los tres.

## Para subagentes posteriores

- **`src/lib/currency.ts`** puede usarse desde cualquier endpoint que necesite conversión CUP/USD. Importar: `import { convertToCup, convertFromCup, convertCurrency, getTotalInCurrency, breakdownPayments, currencyForMethod, isCashMethod, isTransferMethod, formatCurrency } from '@/lib/currency'`.
- **`RestaurantConfig.usdToCup`** es la tasa USD→CUP configurable desde el panel admin (PATCH /api/admin/config con `{usdToCup: <number>}`). Default 320.
- **El dashboard ahora devuelve `salesTodayCUP`, `salesTodayUSD` y `usdToCupRate`** en `stats`. Los componentes frontend que muestren ventas pueden elegir mostrar la moneda equivalente deseada.
- **`salesByMethod` del dashboard incluye `totalCUP` además de `total`** (original) para permitir comparación entre métodos en una moneda común.
- **El mini-servicio realtime-service ya NO acepta conexiones anónimas**: cualquier evento de negocio (order:new, payment:done, etc.) requiere que el socket esté autenticado con un token válido de `rc_session`. Si el frontend no envía el token, el socket se desconecta con `auth:fail`.
- **El frontend `useRealtime` hook ya NO envía userId/role**: envía `{token, areaId?}` donde `token` se lee de la cookie `rc_session`. El servidor extrae userId/role del token.
- **Si se cambia el algoritmo de firma de tokens en `src/lib/auth/token.ts`**, hay que replicar el cambio en `mini-services/realtime-service/index.ts` (función `verifySessionToken` y `computeHmac`).
- **El modelo Session fue eliminado del schema**: cualquier código que intente `db.session.findMany(...)` o `db.session.create(...)` fallará en compilación (TypeScript detecta que el modelo no existe).
- **El cierre diario ahora persiste totales en CUP equivalente** en `totalCash`, `totalTransfer`, `totalSales`. Si se necesita el detalle por moneda original, consultar el audit log del cierre (acción `CLOSE_DAILY`, entity `daily-close`) que incluye `totalCashCUP`, `totalCashUSD`, `totalTransferCUP`, `totalTransferUSD`, `usdToCupRate`.
