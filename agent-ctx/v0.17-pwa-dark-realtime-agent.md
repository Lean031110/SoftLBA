### 2. `/home/z/my-project/public/sw.js` (reescrito, v0.17.0)
Estrategias de cache profesionales:
- **Caches separados** por tipo: `pages`, `assets`, `images`, `fonts` (invalidación granular)
- **Network-first** para navegación (HTML) con fallback a cache y luego página offline
- **Cache-first** para CSS/JS/WASM/fonts (con fallback a logo SVG para imágenes offline)
- **Stale-while-revalidate** para imágenes
- **Background Sync API**: encola POST/PUT/DELETE fallidos en IndexedDB (`softlba-sync-queue`), los reenvía al recuperar conexión (`sync` event con tag `softlba-sync`). Devuelve HTTP 202 `{ok:false, error:"offline-queued"}` mientras está offline.
- **Periodic Sync** (cuando soportado) para refrescar assets críticos
- **Push notifications** mejoradas con plantillas por tipo de evento:
  - `order:new` → "📦 Nuevo pedido" con acciones "Ver pedido" / "Descartar", `requireInteraction: true`
  - `order:ready` → "✅ Pedido listo"
  - `order:status` → "🔄 Estado actualizado"
  - `payment:done` → "💰 Cobro registrado"
  - `stock:low` → "⚠️ Stock bajo"
  - `daily-close` → "🔚 Cierre diario"
  - Vibración `[200,100,200,100,200]`, `renotify: true`, tags únicos por orderId
- **notificationclick**: enfoca ventana existente y navega a la URL del evento; si no hay ventana, abre una nueva
- **Pre-cache del app shell** en install (best-effort con `Promise.allSettled`)
- **Mensajes del cliente**: `SKIP_WAITING`, `GET_VERSION`, `CLEAR_CACHE`
- Avisa a clientes via `postMessage({type:'SW_UPDATED'})` al activarse nueva versión
