# Código de Conducta — SoftLBA

## Nuestro compromiso

Nos comprometemos a hacer de SoftLBA un espacio libre de acoso para
todos, independientemente de edad, género, identidad, orientación,
discapacidad, apariencia, raza, religión o experiencia técnica.

## Comportamiento esperado

- Ser respetuoso y constructivo en discusiones.
- Aceptar críticas técnicas con profesionalidad.
- Enfocarse en lo que es mejor para el proyecto.
- Mostrar empatía hacia otros miembros.

## Comportamiento inaceptable

- Uso de lenguaje sexualizado o imágenes no deseadas.
- Trolling, insultos o comentarios despectivos.
- Acoso público o privado.
- Publicar información privada sin consentimiento.

## Aplicación

Las violaciones pueden reportarse a través de GitHub Issues (privadas)
o directamente al mantenedor del proyecto. Las violaciones resultarán
en advertencias o expulsión del proyecto.

## Alcance

Este código de conducta aplica a todos los espacios del proyecto:
GitHub, issues, pull requests, discusiones y comunicación privada
relacionada con SoftLBA.
